## 🚀 How to Host on GitHub Pages

1. Navigate to your repository on GitHub: [https://github.com/harishdev003/AI-TOOLS](https://github.com/harishdev003/AI-TOOLS)
2. Go to **Settings** > **Pages** (under the "Code and automation" section in the left sidebar).
3. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
4. Under **Branch**, select `main` and leave the folder set to `/ (root)`.
5. Click **Save**.
6. GitHub will build and host your site in ~1 minute at:
   ```
   https://harishdev003.github.io/AI-TOOLS/
   ```

## 💻 Running Locally

Simply double-click [`index.html`](index.html) or any individual quiz HTML file to open it in your browser. No build steps or server dependencies required!
